# Fleetline Project Documentation

Fleetline manages company cars through a React frontend and a Java Spring Boot server. The vehicle directory shows a page of results at a time and supports exact ID lookup, free-text search, filtering, and sorting. The server validates changes before updating its in-memory collection.
